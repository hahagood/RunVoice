# RunVoice Roadmap

## 已完成的阶段基础

- GPS 距离、配速、静止漂移与异常定位恢复
- BLE 心率、自动重连与固定阈值高心率提醒
- 公里、四分之一公里、闭环分段和耳机按键播报
- 断电 checkpoint、原轨迹续写和主动暂存退出
- GPS CSV、摘要海报及公共 Documents 导出
- Room 跑步摘要历史表、按月历史列表和基础月汇总
- 单次详情、部分保存状态与私有文件安全删除

## 下一阶段

1. 历史列表轨迹缩略图
   目标: 让用户能凭路线形状快速辨认很久以前的一次跑步。
   实施边界: 复用历史记录中已有的海报或轨迹引用，在后台按需生成和缓存，不接入在线地图，也不影响实时记录链路。

2. 历史查询与趋势
   目标: 在已有按月列表基础上增加跨月查看能力。
   候选能力:
   - 日期范围筛选与关键词备注
   - 周跑量 / 月跑量趋势
   - 距离、时长与平均配速对比
   - 数据导出

## 更后面的阶段

1. 即时训练分析
   目标: 在跑步过程中给出更有意义的训练状态判断。
   候选能力:
   - 心率区间（Zone）判断
   - 有氧 / 无氧提示
   - 基于年龄和目标区间的个性化上下限提醒
   - 节奏异常提醒

2. 历史分析能力
   目标: 从多次跑步数据中看趋势，而不是只看单次结果。
   候选能力:
   - 心率趋势
   - 配速稳定性
   - 恢复跑 / 训练跑分类
   - 周期训练对比

## 实施原则

1. 优先做“自用时最直接有价值”的功能。
2. 优先保证播报、心率和即时读数可靠，再扩展分析。
3. 先积累足够的真实跑步数据，再决定长期保存字段和训练指标。
4. 不以在线公共地图瓦片作为第三方流量依赖；地图能力优先考虑离线方案。
