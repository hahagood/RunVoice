实现位于 `TraceGeometry.promoteTrailingExitPhase()`；触发条件包含稳定层级数量、尾段长度、历史路线匹配比例和匹配距离，避免普通单圈或一次复走路线误触发。

## 已确认的目标行为

海报应按时间顺序表达路线层级，而不应只按局部空间重合次数着色：

1. 导入线处于第一层。
2. 三圈路线依次向上堆叠，保持现有异色和 2.5D 厚度效果。
3. 第三圈结束后的退出线整体进入第四层。
4. 退出线与导入线重合时，必须像往返跑的去程/回程一样错层绘制。
5. 退出线离开重合区后仍保持第四层，不能中途跳回底层或切换颜色。
6. 层级切换处继续使用平滑坡道过渡，避免突然横移或断线。

预期视觉顺序：

```text
底层导入线
   └─ 第一圈
       └─ 第二圈
           └─ 第三圈
               └─ 第四层退出线
```

这里的“第四层”是视觉遍历阶段，不要求修改实时语音中的圈数或分段措辞。

## 可能的代码原因

相关实现位于：

- `app/src/main/java/com/runvoice/share/TraceGeometry.kt`
- `app/src/main/java/com/runvoice/share/RunSummaryImageSaver.kt`
- `app/src/test/java/com/runvoice/share/TraceGeometryTest.kt`

`TraceGeometry.detectRepeatLevels()` 当前按每个点附近的历史轨迹、距离间隔和方向关系计算 `repeatLevel`，随后按连续距离平滑。它能识别局部复走，却没有“完成三圈后进入退出阶段”的全局状态。因此，退出线离开复走区域后容易重新得到 `level 0`；与导入线重合的部分也可能只被当作普通局部复走，而不是一条需要保持完整层级的退出阶段。

现有往返跑优化只处理“一个闭环内部的去程与回程”。本问题的不同点是：三圈小环并不以整次活动起点为闭环锚点，退出线又发生在最后一圈之后，需要识别局部循环和循环后的剩余路线。

## 下一轮建议实现顺序

### 1. 先补纯 Kotlin 回归测试

在 `TraceGeometryTest` 中构造脱敏的合成路线：

```text
A → B（导入）
B 附近完成三次闭环
B → A → C（退出，其中 B → A 与导入线反向重合）
```

至少断言：

- 导入线为 `level 0`。
- 三圈产生递增层级。
- 退出线从离开第三圈开始直到终点保持同一个新层级。
- 与导入线重合的退出段和导入段层级不同。
- 普通单圈、标准往返跑和无复走开放路线不退化。

不要把真实 GPS 坐标提交为测试夹具；使用米制合成坐标生成测试点。

### 2. 将“局部重合等级”提升为“连续路线阶段”

建议保留现有网格近邻匹配作为底层证据，但在其上增加路线阶段分类：

- 找出稳定的重复闭环区间及各圈边界。
- 将最后一个闭环结束后的所有剩余点标记为 `exit phase`。
- `exit phase` 的层级取当前最大层级加一，并保持到轨迹终点。
- 只有在确认存在重复闭环时才启用此规则，避免普通长路线的尾段被无故抬升。

可以考虑新增纯 Kotlin 边界对象，例如：

```kotlin
data class RoutePhase(
    val startIndex: Int,
    val endIndex: Int,
    val layer: Int,
    val type: RoutePhaseType
)
```

渲染器继续只消费最终层级，不负责推断路线语义。

### 3. 复用现有 2.5D 渲染

`RunSummaryImageSaver` 已支持：

- 每层独立主色、边色和同色高光
- 右上方向的层级位移
- 暗色厚边与阴影
- 35 米范围内的层级坡道过渡

退出线只要获得稳定的新层级，现有 Canvas 绘制通常无需大改。当前专用色板已经避开正文的白、黄、红和背景蓝色：

```text
level 0 绿色
level 1 紫色
level 2 橙色
level 3 洋红色
后续层使用草绿、铜色、薄荷绿
```

### 4. 用真实数据做视觉回归

修复后重新使用 `run-20260710-065902.csv` 生成海报，重点检查：

- 三圈是否仍可分辨。
- 退出线是否整体使用第四层颜色和高度。
- 退出线与导入线的重合段是否能同时看见。
- 退出线较长时是否保持连续，不出现局部掉层。
- 起点、终点和层级过渡是否自然。

同时用 `20260620.gpx` 转换出的约 56.83 km 长轨迹做一次防退化检查，避免阶段规则把普通长路线尾部错误抬升。

## 验收标准

- 2.8 km 真实轨迹中，导入线与退出线不再处于同一视觉层。
- 退出线从第三圈结束点到终点保持完整、连续的第四层样式。
- 重合位置能同时辨认导入线和退出线，不发生视觉合并。

- 普通闭环、A→B→A 往返跑、无复走路线和 57 km 长路线行为保持正确。
- JVM 单元测试、Lint、Debug/Release 构建全部通过。
